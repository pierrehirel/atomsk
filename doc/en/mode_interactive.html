Mode: interactive

Syntax

atomsk

atomsk < script.ats

Description

Running the program without any argument will enter interactive mode, which offers a command-line interpreter. When the program is started by double-clicking the executable, or a link from the system's menu, then it runs in interactive mode.

In this mode the user can enter commands, and they are executed in real-time. Here is the list of general-purpose commands:

  • help Display a summary of commands
  • cd Change directory
  • ls Display a list of files in the current directory
  • pwd Display current working directory
  • print Display current box vectors and atom positions
  • memory Display a summary of the memory used
  • create Create a system from scratch
  • read <file> Read the <file> and load its content in memory
  • write <file> Write the current system into <file>
  • clear Clear the memory, destroying the current atomic system
  • quit Exit this mode and close Atomsk

The command create can be called with the same arguments as the mode --create. If no argument is provided then the user will be prompted.

Some commands related to crystallography are also available:

  • a0 <value> Define lattice constant a0. If other lattice constants (b0,c0) are undefined, they are automatically assigned the same value. Updates the cell vectors H(:,:)
  • b0 <value> Define lattice constant b0. If other lattice constants (a0,c0) are undefined, they are automatically assigned the same value. Updates the cell vectors H(:,:)
  • c0 <value> Define lattice constant c0. If other lattice constants (a0,b0) are undefined, they are automatically assigned the same value. Updates the cell vectors H(:,:)
  • alpha <value> Define angle α (in degrees) between the second and third cell vectors, H(2,:) and H(3,:). Updates the cell vectors H(:,:)
  • beta <value> Define angle β (in degrees) between the first and third cell vectors, H(1,:) and H(3,:). Updates the cell vectors H(:,:)
  • gamma <value> Define angle γ (in degrees) between the first and second cell vectors, H(1,:) and H(2,:). Updates the cell vectors H(:,:)
  • cell Display current cell vectors H(:,:)
  • volume Compute and display the volume of current cell H(:,:)
  • reciprocal Compute and displays reciprocal vectors of current cell H(:,:)
  • hkil2uvw [hkil] Convert Miller-Bravais indices [hkil] into Miller indices [uvw]
  • uvw2hkil [uvw] Convert Miller indices [uvw] into Miller-Bravais indices [hkil]
  • cubic Activate or deactivate cubic symmetry for following commands
  • hexagonal Activate or deactivate hexagonal symmetry for following commands
  • anglehkl [hkl] [h'k'l'] Compute the angle between two crystallographic directions. If no cell is defined: if the 'hexagonal' switch is ON, then hexagonal symmetry is assumed; otherwise cubic symmetry is assumed. If a cell H(:,:) is defined (e.g. with the previous commands a0, b0, alpha, etc.), then this cell is used.
  • normalhkl hkl Find the direction normal to the crystallographic plane (hkl). If no cell is defined: if the 'hexagonal' switch is ON, hexagonal symmetry is assumed; otherwise cubic symmetry is assumed, i.e. the normal to (hkl) plane is simply the [hkl] direction. If a cell H(:,:) is defined (e.g. with the previous commands a0, b0, alpha, etc.), then this cell is used to find the normal. Note that planar indices hkl must not be surrounded by parentheses, as they would interfere with bash interpreter.
  • C11 <value> Define elastic constant C11. If elastic constants C22 and C33 are undefined, they are automatically assigned the same value. Note that this command does not update the stiffness tensor Cij (see below).
  • C22 <value> Idem for C22
  • C33 <value> Idem for C33
  • C12 <value> Define elastic constant C12. If elastic constants C13 and C23 are undefined, they are automatically assigned the same value. Note that this command does not update the stiffness tensor Cij (see below).
  • C13 <value> Idem for C13
  • C23 <value> Idem for C23
  • C44 <value> Define elastic constant C44. If elastic constants C55 and C66 are undefined, they are automatically assigned the same value. Note that this command does not update the stiffness tensor Cij (see below).
  • C55 <value> Idem for C55
  • C66 <value> Idem for C66
  • Cij Construct the full stiffness tensor Cij using values defined previously
  • moduli From Cij defined before, compute and display Young's modulus E, shear modulus G, and Poisson ratio ν
  • aniso From Cij defined before, compute and display anisotropy ratio A = 2C44/(C11−C12), and anisotropy factor H = 2C44 + C12 − C11
  • Sij From Cij defined before, compute and display compliance tensor Sij
  • atom <element> <x> <y> <z> Add an atom of the given <element> at the given position (x,y,z). If coordinates contain fractions (e.g., "1/2" or "2/3"), they are treated as reduced coordinates; otherwise Cartesian coordinates are assumed.
  • rotate <X|Y|Z> <angle> Rotate cell vectors H(:,:) and/or stiffness tensor Cij and/or atom positions (whichever are defined) around the given Cartesian axis (X, Y or Z) by the given angle

The options of Atomsk are also available. They must be called without the leading dash sign (-), and with all their parameters.

Functions can also be called, making Atomsk behave like a calculator. Syntax for writing functions is detailed in this page.

For now the other modes of Atomsk cannot be called from the interactive mode.

Note that only one command (or option) can be issued at a time, and it will take effect immediately.

This mode reads commands from the standard input, which by default is the keyboard. In GNU/Linux environments it is possible to use the standard redirection (<) to use a file as standard input (instead of the keyboard). That means that commands can be saved in a text file and be used as a script, using the standard redirection (see examples below).

When running in interactive mode the verbosity level is automatically reset to 1 if it is set to 0 or 2.

Examples

  • atomsk

    Just enter "atomsk" and follow the instructions.

  • user@computer:~$ atomsk
    >>> Atomsk is a free Open Source software, for details type 'atomsk --license'.
    >>> Atomsk command-line interpreter:
    ..> Type "help" for a summary of commands.
    user@atomsk> read initial.xsf
    user@atomsk> duplicate 6 6 2
    user@atomsk> write final.xsf cfg
    user@atomsk> quit

    The user just entered "atomsk" without argument, thus running the program in interactive mode. In interactive mode, Atomsk waits for commands and executes them in real-time. In this example, the user reads a file ("initial.xsf"), uses the option -duplicate, and then writes the system into output files "final.xsf" and "final.cfg". Note that in interactive mode, options must be used without the leading dash sign: use "duplicate" instead of "-duplicate". The last command "quit" exits Atomsk.

  • script.ats

    #!/usr/local/bin/atomsk
    create fcc 4.02 Al
    duplicate 20 20 1
    deform x 0.3% 0.33
    wrap
    write deformed_al.xsf

    atomsk < script.ats

    Some commands were written in the text file "script.ats". Then, atomsk is run in interactive mode (because no command-line argument is present) and will execute commands from the standard input, i.e. the file "script.ats". Note that in interactive mode, the options must not have their leading dash sign, e.g. write "wrap" and not "-wrap".
